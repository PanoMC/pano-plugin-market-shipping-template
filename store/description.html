Example Carrier for Pano Market

Example Carrier is a parcel carrier. This plugin adds it as a shipping provider to Pano Market, which must be installed and running: it is a required dependency of this plugin.

What it supports

  • Live shipping rates at checkout, with the services Example Carrier cannot offer for a parcel listed separately.
  • Buying a label from the Pano panel: PDF or ZPL for thermal printers, delivered at once or fetched a moment later.
  • Cancelling a label that has not been picked up yet.
  • Tracking: Pano Market asks Example Carrier for the state of open shipments, and a tracking webhook makes it ask sooner.
  • The prepaid balance of your Example Carrier account, shown before a label is bought.
  • Address validation and test mode against the Example Carrier sandbox.
  • One parcel per shipment.

Verification level

Unverified: this plugin has not been tested against a live or sandbox Example Carrier account. Its tracking handling was checked only with sample answers written from the documented protocol.

Setup

  1. Install Pano Market, then this plugin, and open Market, Shipping, Example Carrier in the panel.
  2. Paste the API key and the API secret from the developer section of your Example Carrier account.
  3. Fill in the sender address and the default parcel size.
  4. Copy the webhook URL shown in the form into your Example Carrier account as a tracking webhook. The webhook is not signed: Pano Market always asks Example Carrier for the real state before it believes a notification.
  5. Press “Test connection”, then enable the carrier and bind a shipping method to one of its services.
